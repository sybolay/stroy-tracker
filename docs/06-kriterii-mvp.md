# Критерии готовности MVP

1. Приложение запускается по инструкции.
2. Можно выбрать или создать проект.
3. На доске отображаются три колонки.
4. Можно создать, изменить и удалить карточку.
5. Карточку можно перетащить между колонками.
6. После обновления страницы данные сохраняются.
7. Поиск или фильтр работает.
8. Доска удобна на компьютере и мобильном экране.
