# Экраны MVP

| Экран / компонент | Назначение |
|---|---|
| Проекты | Выбор проекта и создание нового |
| Kanban-доска | Колонки и карточки задач |
| Модальное окно задачи | Создание и редактирование карточки |
| Фильтр | Быстрый поиск и фильтрация |

Авторизацию и отдельный дашборд можно заменить простым заголовком проекта.
