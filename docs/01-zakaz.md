# Учебный заказ: «СтройТрекер»

| Параметр | Решение |
|---|---|
| Цель | Учебный трекер задач строительного проекта |
| Главный сценарий | Создать проект, добавить задачи и перемещать их по Kanban-колонкам |
| Формат | Адаптивное веб-приложение |
| Пользователи | Один пользователь или простая авторизация |
| Приоритет | Рабочая Kanban-доска, минимальный код, быстрая демонстрация |
| Бюджет и сроки | Учебный проект; разработка в ограниченное время |
