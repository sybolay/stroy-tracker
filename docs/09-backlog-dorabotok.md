# Backlog после MVP

| Приоритет | Доработка | Когда добавлять |
|---|---|---|
| 1 | Supabase Auth и пользователи | После стабильного localStorage-MVP |
| 2 | Синхронизация данных между пользователями | После авторизации |
| 3 | Этапы строительного проекта | Если нужна связь Kanban с объектом |
| 4 | Комментарии и история изменений | После основной доски |
| 5 | Заявки на материалы | Как отдельный Kanban-поток |
| 6 | Фото и документы | После настройки файлового хранилища |
| 7 | Уведомления | После появления реальных пользователей |
| 8 | Календарь и отчёты | Только при наличии времени |
| 9 | AI-функции в приложении | После MVP: описание задачи, группировка и подсказки |

## Возможные AI-функции

- создание черновика задачи по короткому описанию;
- автоматическое предложение приоритета;
- суммаризация комментариев;
- поиск задач обычным языком.

AI-функции не входят в учебный MVP: они требуют API, обработки ошибок и контроля стоимости запросов.
