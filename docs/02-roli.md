# Роли пользователей

Для урока достаточно одного демо-пользователя без сложной ролевой модели.

| Роль | Возможности |
|---|---|
| Пользователь | Создание проектов, задач, редактирование и перемещение карточек |

Авторизацию можно добавить через Supabase Auth, но она не должна блокировать разработку доски.
