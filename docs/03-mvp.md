# MVP: Kanban-доска

| Блок | Минимальная реализация |
|---|---|
| Проекты | Список проектов; название и описание |
| Доска | Три колонки: «К выполнению», «В работе», «Готово» |
| Карточка | Название, описание, приоритет, срок |
| Действия | Создать, изменить, удалить, переместить карточку |
| Фильтр | Поиск по названию или приоритету |
| Данные | Сохранение в Supabase или локальном mock-хранилище |
| Интерфейс | Адаптивная доска и модальное окно карточки |

## Не входит в MVP

Роли, заявки на материалы, файлы, чат, уведомления, календарь, склад, отчёты,
интеграции и отдельное мобильное приложение.
