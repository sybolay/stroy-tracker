# Короткий промпт для запуска разработки

```text
Разработай учебное приложение «СтройТрекер» — Kanban-доску задач строительного проекта.

Стек: Next.js, TypeScript, Tailwind CSS, shadcn/ui, dnd-kit. Для данных используй localStorage; Supabase подключи только если это не замедлит MVP.

MVP:
- список проектов;
- выбор и создание проекта;
- три колонки: «К выполнению», «В работе», «Готово»;
- карточка задачи: название, описание, приоритет, срок;
- создание, редактирование и удаление карточек;
- drag-and-drop между колонками;
- поиск или фильтр;
- сохранение данных после обновления страницы;
- адаптивный интерфейс.

Не добавляй авторизацию, роли, заявки, чат, файлы, календарь и отчёты.

Работай маленькими этапами:
1. Покажи структуру файлов и модель данных.
2. Создай интерфейс доски с mock-данными.
3. Добавь CRUD карточек.
4. Добавь drag-and-drop через dnd-kit.
5. Добавь localStorage, фильтр и адаптивность.
6. Проверь сценарии и обнови README.

Не генерируй весь проект одним ответом. На каждом шаге показывай только необходимые файлы и кратко объясняй изменения. Не добавляй зависимости без необходимости.
```
