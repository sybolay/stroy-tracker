# Рекомендуемый быстрый стек

| Слой | Технология |
|---|---|
| Приложение | Next.js + TypeScript |
| UI | Tailwind CSS + shadcn/ui |
| Drag-and-drop | dnd-kit |
| Данные | Supabase (PostgreSQL) |
| Состояние | React hooks; без Redux |
| Деплой | Vercel |
| Помощь AI | Генерация компонентов, схемы БД и тестовых данных малыми шагами |

Если подключение Supabase занимает много времени, начать с localStorage и заменить слой данных позже.
