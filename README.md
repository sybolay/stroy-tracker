# СтройТрекер

Учебный Kanban-трекер строительных задач.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`).

Данные проектов и задач сохраняются в `localStorage` браузера. Перетаскивайте карточки между колонками, создавайте задачи кнопкой «Новая задача» или редактируйте карточку кликом.
